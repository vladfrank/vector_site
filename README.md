# ЦУКЗ «Вектор» — исходный проект MVP

Адаптивный сайт по концепции из презентаций: глубокий синий `#101D30`, бирюзовый `#12B8A6`, светлый `#F7F9FC`, второстепенный текст `#65758B`.

## Быстрый запуск

Требуется **Python 3.10 или новее**. Сторонние пакеты, Node.js и сборка не нужны.

1. Распакуйте архив.
2. Откройте терминал в папке `vector-site`.
3. Выполните `python server.py` (на macOS/Linux — `python3 server.py`).
4. Откройте **http://127.0.0.1:8000**.
5. Админка: **http://127.0.0.1:8000/admin**. Случайный пароль будет напечатан в терминале при запуске.

Windows: можно дважды нажать `start.bat`, затем перейти по адресу из терминала. Не открывайте `index.html` напрямую: формы и роуты работают через сервер.

Для постоянного пароля задайте переменную окружения (минимум 12 символов) перед запуском:

PowerShell:
```powershell
$env:VECTOR_ADMIN_PASSWORD="ЗАМЕНИТЕ-на-свой-длинный-пароль"
python server.py
```

macOS / Linux:
```bash
export VECTOR_ADMIN_PASSWORD='ЗАМЕНИТЕ-на-свой-длинный-пароль'
python3 server.py
```

По умолчанию сервер доступен только на вашем компьютере. Для тестирования в локальной сети: `python server.py --host 0.0.0.0 --port 8000`. Открывайте с другого устройства по IP компьютера.

## Что реализовано

- Главная: центральный новостной блок с фотографией, заголовком, описанием, датой, стрелками и автоматической остановкой при взаимодействии. Ниже — услуги, кейсы и FAQ. Рекламный заголовок и кнопки первого экрана удалены.
- Каталог и подробные страницы услуг; 4 направления, 2 фокусных на главной.
- Каталог кейсов с фильтрами. Интерактивный маршрут по этапам, прогресс и раскрытие полного текста.
- Новости: список и подробный текст без тегов. Загрузка фотографии в редакторе новости, замена, удаление привязки и описание для доступности. Фото отображается на главной, в списке и на странице новости.
- О компании, контакты, форма обращения, проект текста обработки данных, экран 404.
- Серверная запись заявок в SQLite. Валидация, подтверждение без номера обращения, защита от повторного клика во время отправки.
- Админка: пароль, сессия, список/поиск/фильтры заявок, ответственный, внутренний комментарий, статусы, архив и история изменений.
- Редакторы услуг, новостей, кейсов: создание, сохранение, предпросмотр, черновик/публикация, снятие с публикации, удаление с подтверждением.
- Настройки: описание компании, телефон, email, адрес, реквизиты, FAQ.
- Адаптивная навигация, клавиатурный доступ, учёт reduced motion, вывод пользовательских текстов без выполнения HTML.

Кейсы и новости явно обозначены как демонстрационные. Указанные в них результаты вымышлены для показа механики. Контакты и сведения о специалистах не выдумывались.

## Структура файлов

```text
vector-site/
  server.py           HTTP-сервер, API, авторизация, база данных
  seed.json           начальные услуги, новости и кейсы
  public/
    index.html        общий каркас
    styles.css        адаптивные стили
    app.js            страницы, клиентские роуты и механика
  tests/test_api.py   интеграционные проверки
  ROUTES.md           карта страниц и API
  start.bat           запуск для Windows
  start.sh            запуск для macOS/Linux
  README.md
```

`data/vector.db` создаётся автоматически при первом запуске. В ней хранится весь контент, настройки и заявки. Начальные данные загружаются один раз. Для сброса остановите сервер и удалите базу (это удалит заявки). Фотографии находятся в `data/uploads/`. Для переноса или резервной копии остановите сервер и скопируйте всю папку `data`, включая базу и фотографии. Если задан `VECTOR_DB`, папка `uploads` создаётся рядом с указанной базой.

Можно переопределить путь к базе переменной `VECTOR_DB`. Сессии хранятся в памяти и сбрасываются при перезапуске; контент и заявки сохраняются.

## Работа администратора

Откройте `/admin` → введите пароль из терминала. Создайте новость или услугу, заполните поля и включите «Опубликовано», затем сохраните. Без этой галочки материал доступен только в админке. Предпросмотр показывает текущий текст формы до сохранения.

В редакторе кейсов этапы задаются по строкам: `Название | Текст этапа`. Не более 10 этапов. В FAQ аналогично: `Вопрос | Ответ` (до 20 вопросов).

Архив — отдельный признак, он сохраняет итоговый статус обращения. При изменении карточки в историю попадают время UTC и сохранённые значения. В MVP один общий администратор; персонального аудита сотрудников нет.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты используют временную БД. Проверяют создание заявки, согласие, запрет доступа без входа, CSRF, черновик/публикацию, изменение статуса и историю, сохранение после реального перезапуска сервера, выход и HTTP-доступность страниц.

## Границы версии и публичный запуск

Это самостоятельный локально запускаемый MVP; архив не означает публикацию на домене. Стандартный сервер Python подходит для разработки и демонстрации. Для публичной эксплуатации нужен production-сервер/адаптер, HTTPS через reverse proxy, резервные копии, мониторинг, серверный rate limit формы или CAPTCHA. Для HTTPS задайте `VECTOR_SECURE_COOKIE=1`.

Текущая защита: SameSite/HttpOnly cookie, CSRF для административных действий, проверка Origin, ограничение попыток входа, ограничение тела запроса, параметризованный SQL, CSP и экранирование текстов. Память сессий/лимита входа рассчитана на один процесс. Нет ролей сотрудников, сброса пароля по email и 2FA.

Почтовые уведомления, CRM, документы-вложения к заявкам, личный кабинет клиента и платформа сопровождения сделок не подключены. Формы сохраняют заявки в админке, не рассылают email. Политика обработки данных — проект, перед публичным сбором данных замените её согласованным документом и реквизитами оператора. Реальные кейсы, новости, фотографии, контакты и документы необходимо согласовать. Удаление материала необратимо, поэтому регулярно делайте резервные копии БД.


## Фотографии новостей

Откройте «Админка → Новости → Добавить» или существующую новость. В блоке «Фотография новости» выберите файл JPEG, PNG или WebP до 5 МБ. Дождитесь сообщения об успешной загрузке, укажите описание изображения и сохраните новость. Во время загрузки сохранение отключено. Кнопка «Убрать фотографию» снимает привязку после сохранения. Файлы автоматически не удаляются с диска, чтобы не повредить повторно использованные изображения.

Имена файлов генерирует сервер. Проверяются размер, MIME и сигнатура формата; полноценного декодирования или изменения размера на сервере нет. SVG и удалённые URL не принимаются. Медиафайлы доступны по прямой ссылке, поэтому не загружайте конфиденциальные материалы, включая фотографии для черновиков. Исходные изображения не перекодируются; при необходимости заранее удаляйте EXIF.

В архиве нет чужих или случайных фотографий: загрузите собственные через редактор. Для новостей без фотографии отображается графическая заглушка. Старую БД можно сохранить: новые поля `image` и `image_alt` поддерживаются без миграции.

## Оформление исходников

Python-код и комментарии оформлены по PEP 8: отступ 4 пробела, длина строки до 79 символов, раздельные импорты, документация функций и комментарии к важным проверкам. HTML, CSS и JavaScript отформатированы отдельно; PEP 8 применяется к Python.

Необязательные инструменты разработки (не требуются для запуска сайта):

```bash
python -m pip install -r requirements-dev.txt
python -m pycodestyle server.py tests/test_api.py
python -m black --check --line-length 79 --target-version py310 server.py tests/test_api.py
```


## Обновление формы и главной страницы

Новостной блок растянут на всю ширину окна. Кнопка «Пауза / Продолжить» удалена; стрелки переключения остаются. Автопрокрутка останавливается при наведении, фокусе или ручном переключении. При включённом reduced motion автопрокрутка не запускается.

В заявке нет направления услуги. Описание задачи необязательно. Обязательные поля: компания, имя, способ связи, контакт и согласие. Доступны телефон, email, Telegram и WhatsApp. Для Telegram укажите @username или телефон, для WhatsApp — телефон. После отправки клиент видит «Спасибо! Мы скоро свяжемся с вами выбранным способом». Внутренний номер остаётся в админке.

В редакторе новости есть кнопка «Предпросмотр на главной». Она открывает полный макет главной с текущим текстом и фотографией новости, даже до сохранения. Кнопки «Компьютер» и «Телефон» меняют ширину предпросмотра. Предпросмотр ничего не публикует и не меняет публичные данные. Закройте окно, чтобы продолжить редактирование; Escape также закрывает окно.

При обновлении проекта сохраните свою папку `data/`. Сервер автоматически добавит поле способа связи в старую БД при первом запуске. Старые заявки получают значение «Не указан»; их данные сохраняются.


## Высота новостей и обновлённое оформление

Новостной блок имеет фиксированную высоту: 560 px на компьютере и 720 px при ширине до 780 px. Фотография абсолютно позиционирована внутри области слайда и кадрируется через `object-fit: cover`, поэтому её исходные пропорции не меняют высоту блока. Заголовок ограничен тремя строками, а анонс — двумя; полный текст открывается через «Читать новость». Такая же вёрстка применяется в предпросмотре.

Секция «02 / Подход» удалена из общего шаблона главной и предпросмотров. Следующие секции перенумерованы. Уточнены типографика, отступы, карточки, кнопки и поля форм; исходная цветовая палитра сохранена.
