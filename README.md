# ЦУКЗ «Вектор» — сайт и админка

Текущая версия начинает главную страницу с интерактивной схемы жизненного цикла компании. Каталог из 13 услуг, биографии и цитаты основателей подготовлены по материалам «ЖЦ+услуги.pptx» и «Для сайта материал_v2 (1).docx».

## Что работает

- Первый экран: схема жизненного цикла бизнеса, выбор этапа и ссылки на услуги этого этапа.
- Каталог услуг и отдельные страницы. Группы соответствуют четырём направлениям консалтинга из документа.
- Страница «О компании» с Алексеем Бондаревым и Натальей Киприяновой, биографиями и цитатами. Фото добавляются через админку; до загрузки показаны инициалы.
- Телефон, проверка рабочего времени, предложение связаться позже или открыть контакты. Телефон, дни, часы и часовой пояс задаёт администратор.
- Защищённая админка: услуги, основатели, настройки, а также сохранённые новости, кейсы и старые обращения.
- Новости и кейсы сейчас скрыты в публичной части, включая прямые страницы и публичный API. Их записи не удалены. В админке они доступны для редактирования; публикационные флаги сохранены.
- Загрузка фотографий в JPEG, PNG или WebP до 5 МБ, предпросмотр, замена и снятие привязки.
- Адаптивная вёрстка и фавиконка в фирменной палитре.

## Локальный запуск

Нужен Python 3.10 или новее. Для запуска сайта сторонние библиотеки не требуются.

```bash
python server.py
```

На macOS/Linux можно использовать `python3 server.py`. Откройте `http://127.0.0.1:8000`. Для Windows также есть `start.bat`. Админка — `/admin`. При локальном запуске случайный временный пароль печатается в терминале. Для постоянного пароля задайте `VECTOR_ADMIN_PASSWORD` длиной от 12 символов.

Не открывайте `index.html` как обычный файл: страницы и данные работают через сервер.

## Обновление на хостинге

1. Сделайте резервную копию своей папки `data`.
2. Замените файлы проекта содержимым архива, **сохранив свою папку `data`**.
3. Обязательно загрузите новые `site_content.py` и `company_content.json` рядом с `server.py`. Файл `contact.py` из прошлой версии тоже должен оставаться рядом.
4. На PythonAnywhere нажмите Web → Reload. Конфигурацию WSGI менять не нужно.
5. Обновите страницу браузера через Ctrl+F5.

Сервер однократно добавит новый каталог и карточки основателей в существующую БД. Контакты, расписание, старые обращения, новости, кейсы и изображения сохраняются. Прежние типовые направления услуг сохраняются в админке как черновики, чтобы они не дублировали новый каталог. Пользовательские направления с изменёнными названиями не скрываются автоматически.

## Основатели и фото

Откройте **Админка → Основатели**. В каждой карточке можно изменить имя, роль, биографию, цитату и описание фото.

Для фотографии: выберите файл → дождитесь сообщения об успешной загрузке → нажмите «Сохранить карточку». Во время загрузки сохранение отключено. «Убрать фото» снимает привязку после сохранения. Физические файлы автоматически не удаляются, чтобы не повредить другие публикации, использующие то же изображение.

Загруженных портретов в исходных документах не было, поэтому в архиве нет выдуманных фотографий людей.

## Схема и услуги

В схеме доступны этапы: старт, рост, зрелость, спад, банкротство, возрождение. Списки услуг соответствуют блокам презентации. Для старта в презентации нет отдельного перечня, поэтому показана ссылка на полный каталог.

Первый экран построен вокруг миссии «Всегда рядом, когда меняются задачи и масштабы». Шапка выделена глубоким синим цветом, логотип «Вектор» и навигация увеличены. Прежний крупный слоган стал второстепенной строкой. На компьютере компактная тёмная схема расположена слева, услуги выбранного этапа — справа. Яркий активный этап и подписи «Услуги ↗» объясняют интерактивность. На телефоне используются крупные кнопки выбора этапа и последовательное расположение блоков.

Длинные названия вынесены в панель под графиком: выбор этапа меняет список ссылок, без наложения текста на кривую. График масштабируется без горизонтальной прокрутки. Его высота на компьютере ограничена высотой окна. На телефоне подписи вынесены в крупные кнопки, чтобы не уменьшать текст на схеме до нечитаемого размера.

Названия и исходное наполнение находятся в `company_content.json`. Связи этапов с услугами задаются там через `service_ids`. Сами тексты услуг после первого запуска можно менять в админке. Изменение JSON не перезаписывает уже сохранённые тексты автоматически.

Краткие описания услуг составлены для сайта по их названиям и направлениям; биографии и цитаты основаны на документе компании. Предыдущие демонстрационные кейсы не представлены как реальные проекты.

## Контакты и расписание

Перед запуском заполните **Админка → Настройки**: настоящий телефон, email, при необходимости Telegram (`@username`) и WhatsApp. Установите часовой пояс, рабочие дни, начало и конец смены. Пример по умолчанию: Пн–Пт, 09:00–18:00, Asia/Novosibirsk.

Кнопка звонка запрашивает актуальное состояние на сервере. В рабочее время открывается набор номера через `tel:`; устройство может запросить подтверждение или приложение для звонков. В нерабочее время отображается ближайшая смена и ссылка на контакты. Поддерживаются ночные смены и остановка звонков, если снять все дни. Праздничные дни автоматически не учитываются. Прямой ручной звонок на номер сайт ограничивать не может.

## Данные и резервные копии

База — `data/vector.db`, изображения — `data/uploads/`. Для резервной копии остановите сервер и скопируйте всю папку `data`. На PythonAnywhere постоянный пароль находится в `data/.admin-password`, если не задан через окружение. Храните этот файл вместе с резервной копией, не публикуйте его.

Сессии и ограничение попыток входа хранятся в памяти процесса. Текущая версия рассчитана на один worker; после перезапуска требуется снова войти в админку. Для нескольких workers потребуется общее хранилище сессий.

## Проверки и оформление кода

```bash
python -m unittest discover -s tests -v
```

Python оформлен по PEP 8. Необязательные инструменты разработки перечислены в `requirements-dev.txt`; они не нужны на хостинге для запуска сайта.

```bash
python -m pip install -r requirements-dev.txt
python -m pycodestyle server.py contact.py site_content.py tests
```

## Публичная эксплуатация

Для WSGI используйте `wsgi:application`. На VPS можно запускать его через Gunicorn за Nginx; выбирайте один worker и настройте автозапуск, HTTPS и резервные копии. Стандартный `python server.py` предназначен для локальной демонстрации. При HTTPS задайте `VECTOR_SECURE_COOKIE=1`.

Защита включает пароль, HttpOnly/SameSite cookie, CSRF, проверку Origin, ограничения размера запросов и попыток входа, параметризованный SQL и экранирование текстов. Изображения проверяются по типу, размеру и сигнатуре, но не перекодируются; SVG-загрузки не принимаются. Загруженные файлы доступны по прямой ссылке, поэтому не используйте конфиденциальные материалы. Ролей сотрудников, 2FA, CRM, почтовых уведомлений и автоматического учёта праздников нет.


## Обзор направлений и фильтр услуг

Страница `/services` показывает все четыре направления консалтинга. Каждое направление раскрывается и показывает свои услуги; переход по услуге открывает её подробную страницу. Фильтр «Направление» оставляет выбранную группу и раскрывает её. Под фильтром показывается количество найденных услуг. Выбор отражается в параметре `direction` адреса страницы и может сочетаться с фильтром `stage`.

На главной кнопка «Все направления и услуги» находится непосредственно под списком услуг выбранного этапа. В верхнем меню также есть пункт «Направления и услуги».

Для обновления оформления замените `public/index.html`, `public/app.js`, `public/styles.css` и `public/business-cycle.svg`. Серверные файлы и папку `data` менять не требуется.
